# FinPilot AI

An agentic financial research and portfolio optimization platform.

## Features

- Company Research
- Financial Statement Analysis
- Financial News Analysis
- Sentiment Analysis
- Portfolio Optimization
- Explainable AI Reports
- Multi-Agent Orchestration (LangGraph)
- RAG over SEC Filings
- Portfolio Monitoring

## Tech Stack

- Python
- Django REST Framework
- PostgreSQL
- LangChain
- LangGraph
- ChromaDB
- React (or Streamlit MVP)
- Docker
- Celery
- Redis
